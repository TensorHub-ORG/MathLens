# 0007：块级内容 Golden 与抽样基线

状态：Accepted
日期：2026-08-22

## 背景

页面级内容验证只能表达“整页全部检查”，无法诚实记录风险优先和抽样复核。将少量抽样结果
标成整页真值会夸大覆盖率；要求逐页全量复核又会使 Golden 建设成本不可接受。

## 决策

1. Golden Schema v3 将 `transcription` 与 `formula` 验证证据下沉到 block；页面只保存
   `layout` 与 `reading_order` 验证。
2. 评测器只统计已验证 block，并同时报告可验证 block 总数与已验证 block 数量。
3. 首次校准全量复核公式；无明显风险的文本采用 block ID 稳定哈希抽样 10%。缺失内容和
   确定性语法风险始终进入队列。
4. Workbench 同时显示原图裁剪和解析内容；逐块确认后自动前往下一项。
5. 读取 v2 数据时，将已完成的页面内容验证迁移到相应 block，并在下次保存时写出 v3。

## 后果

- 内容指标的样本量与人工证据一致，不再借用页面级状态；
- 相同数据每次生成相同抽样队列，回归结果可复现；
- 第 7 页已经完成的内容复核可保留，其余页面无需重新检查布局和阅读顺序；
- 公式首轮仍需逐块视觉确认，因为 KaTeX 可渲染不代表识别语义正确。

## 未选择的方案

- 不把 KaTeX 渲染成功自动视为公式正确；它只能排除部分语法错误。
- 不保留页面级内容验证作为第二套并行语义，避免两处状态冲突。
