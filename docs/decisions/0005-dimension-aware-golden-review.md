# 0005：Golden 分维度验证

状态：Superseded by [0007](0007-block-level-content-golden.md)
日期：2026-08-21

## 背景

版面框、阅读顺序、文本转写和公式 LaTeX 的复核方式与成本不同。单一的页面 `reviewed`
状态无法说明人工实际检查了哪些内容，也会让解析器建议被错误地当作内容真值。

## 决策

1. Golden Schema v2 删除页面级工作流状态，改用 `verified_aspects` 独立记录 `layout`、
   `reading_order`、`transcription` 和 `formula`。
2. 除布局外的验证都依赖已验证布局；顺序、文本和公式还必须满足各自的完整性约束。
3. 评测器只为已验证维度生成指标，未验证内容以 `null` 和零样本显式呈现。
4. 编辑只撤销受影响的验证维度；布局变化会撤销全部依赖维度。
5. 工作台提供公式渲染和确定性风险检查，人工优先检查高风险内容，其余内容采用抽样复核。

## 后果

- 当前 12 个代表页只保留已经完成的布局与阅读顺序验证；
- 现有结果可以作为结构解析基线，不能宣称文本 CER 或公式精确率；
- 内容真值可以增量建设，不需要每次重复检查模型已经稳定通过的版面；
- Schema v1 不再兼容，避免长期保留含义不明确的状态分支。
